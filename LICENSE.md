### Dependencies

WebSUMO uses the following open source libraries (see requirements.txt and 
package.json for full list and versions):

- **SUMO** (Eclipse Public License 2.0) — traffic simulation
- **libsumo** (EPL 2.0) — Python bindings for SUMO
- **NATS** (Apache License 2.0) — message broker
- **FastAPI** (MIT) — Python web framework
- **deck.gl** (MIT) — WebGL-powered visualization
- **MapLibre GL JS** (BSD 3-Clause) — map rendering
- **React** (MIT) — UI framework

See individual dependency licenses in their respective repositories.
